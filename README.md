# СметаПро

СметаПро — браузерное PWA-приложение для составления строительных смет, расчёта стоимости работ и материалов и подготовки готового расчёта для заказчика.

## Возможности

- каталог строительных работ и материалов с профилями;
- поиск по названию, категории, опечаткам и синонимам;
- отдельные позиции работ и материалов;
- ручное добавление нестандартных позиций;
- количество с шагом 0,5;
- цены и итоги в целых копейках;
- скидка, применяемая к стоимости работ;
- локальное сохранение смет в IndexedDB с localStorage backup;
- кеширование каталогов и работа без сети после первоначальной загрузки;
- экспорт и восстановление сметы через HTML/JSON;
- векторный PDF-экспорт;
- установка как PWA.

## Данные

Канонический источник каталогов находится в `data/` внутри этого репозитория:

`data/index.json` → `data/profiles/<id>/manifest.json` → `catalog.json`, `categories.json`, optional `search-synonyms.json` и `config.json`.

Локальная и удалённая проверка используют общий валидатор из `src/services/catalogValidation.ts`.

Legacy-репозиторий `getto-dev/check-data` больше не является источником истины и сохранён только как snapshot для обратной совместимости старых raw URL.

## Разработка

```bash
npm ci
npm run dev
```

Перед изменением `main`:

```bash
npm run validate:data
npm run typecheck
npm test
npm run build
npm run e2e
```

Для production используется GitHub Pages с base path `/smeta/`.
